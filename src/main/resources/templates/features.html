Application Security

Security Built Into StockFlow

Protecting application resources through authentication and authorization.

Secure Authentication

Users must authenticate before accessing protected inventory management pages and restricted application operations.

BCrypt Password Hashing

Spring Security uses BCrypt password encoding to verify credentials without comparing plain-text stored passwords.

Role-Based Authorization

ADMIN, STAFF and VIEWER roles provide different access permissions based on user responsibilities.

Protected Routes

Restricted application URLs are protected using Spring Security request rules and controller-level authorization.

Dynamic Navigation

Navigation links, account information and product action buttons adapt to the authenticated user's permissions.

CSRF Protection

Sensitive POST requests are protected against cross-site request forgery using Spring Security's CSRF tokens.

Restricted Product Deletion

Only administrators are authorized to delete products. Staff and viewers cannot perform deletion operations.

Secure Logout

Logout terminates the authenticated session and clears security information to prevent continued authenticated access.

Access Denied Protection

Authenticated users attempting to access restricted resources receive an HTTP 403 Forbidden response.
