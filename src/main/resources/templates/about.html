About StockFlow

StockFlow is a warehouse inventory management application developed using Spring Boot, Thymeleaf, Bootstrap, and Spring Data JPA.

Our Purpose

Our goal is to help businesses organize products, monitor stock quantities, and improve inventory management through a simple web application.

Technologies Used

  • Java and Spring Boot
  • Thymeleaf and Bootstrap
  • Spring Data JPA
  • H2 Database
  • Git and GitHub
